# INFR Assignment 1 Portfolio

## Description

This portfolio contains a Home page, an About Me page, a Projects page, and a Contact Me page. It is styled using CSS for full screen desktop, tablet, and phone screen sizes.

The purpose of the website is to introduce myself, talk about some of my interests, show some of the projects I have worked on, and provide a way for visitors to contact me.

## Responsive Design

As stated earlier, this website is responsive and works on full screen, tablet, and phone screen sizes.

Full screen = 960px and more
Tablet screen = 481px - 959px
Phone screen = 480px and less

I also included the viewport meta tag on all four pages so the website can adjust properly when viewed on different devices.

I tested the website at desktop, tablet, and smartphone sizes to make sure the pages, navigation, images, video, and forms still display and work properly. This was done using responsive design.

## Colour Scheme

I used a colour scheme based on colours from Adobe Color. I chose colours that work well together and give the website a bright but also simple appearance.

### The Main Colours Used

#23B7D9 - used for the borders, buttons, and some parts of the gradients.
#1FA65A - used for hover effects and parts of the gradients.
#F2E2CE - used as the main background colour for the website and sections.
#8176D7 - used for the navigation bar, headings, labels, and part of the footer gradient.
#333333 - used to change some wording and heading to be more clear according to wave.

White and dark grey were also used in different areas of the website to make the content easier to read.

## Gradients

The first gradient is a normal linear gradient that goes from top to bottom. It was used in the header, where the colour changes from `#23B7D9` to `#1FA65A`.

The second gradient is an angled linear gradient that I used in the footer. It uses a 135 degree angle and changes from `#8176D7` to `#23B7D9`.

## Testing

I tested the website during development to make sure the pages and features were working correctly.

I tested the website at desktop, tablet, and smartphone screen sizes to make sure the responsive layouts worked correctly.

I also tested the navigation links between all four pages to make sure they connected to the correct pages.

The Contact Me form was tested to make sure the required fields work correctly. I also tested the email field to make sure it uses the browser's HTML5 email validation. The Clear Form button was also tested.

The video on the About Me page was tested to make sure the controls, poster image, and video playback work correctly.

The website will also be checked using the W3C HTML Validator, W3C CSS Validator, W3C Link Checker, and WAVE accessibility tool before the final submission.

## Sources and Code Documentation

The HTML and CSS for this portfolio were created by me using the concepts and examples covered in the INFR3120 course material.

I used HTML5 semantic elements such as header, nav, main, article, section, figure, footer, and form to organize the website.

The responsive design was created using CSS media queries for desktop, tablet, and smartphone screen sizes.

The video on the About Me page is my own video, and the images used on the website are my own images.

The colours used in the website were selected using Adobe Color and are documented in the Colour Scheme section above.
